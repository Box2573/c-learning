先看程式碼
```c++
#include<SFML/Graphics.hpp>
int main()
{
    sf::RenderWindow window(
        sf::VideoMode({1280, 720}),
        "C++ Sandbox"
    );

    while (window.isOpen())
    {
        // 1. 處理事件
        while (const auto event = window.pollEvent())
        {
            if (event->is<sf::Event::Closed>())
            {
                window.close();
            }
        }
    }

    return 0;
}
```
- 要include標頭檔`SFML/Graphics.hpp`
- `RenderWindow window`用來決定視窗大小並存到一個叫window的變數中
	- `1280, 720`為視窗大小
	- `"C++ Sandbox"`為該視窗的標題
- 如果只有繪製視窗他會因為跑到return所以會看到他閃一下就關掉了
	- 因此用while迴圈讓他無限執行直到關閉視窗
- 但此時只有視窗卻不能移動視窗、關閉視窗因為我們沒有接收視窗事件因此
	- `window.pollEvent()`為視窗事件
	- 但如果只打`window.pollEvent()`會發現視窗是可以移動了但不能關閉，因為我們沒對事件做處理
		- 用一個變數把事件存下來`const auto event`
			- `const`表示我只讀取該事件不做改動
			- auto讓他自己判斷變數型態不然`window.pollEvent()`會回傳`std::optional<sf::Event>`要打很長一串
	- 把視窗事件也放在一個while表示有事件才進迴圈處理
- `event->is<sf::Event::Closed>()`為視窗關閉事件
	- `event->is`使用event的成員因此用->
	- is<>為一種template
