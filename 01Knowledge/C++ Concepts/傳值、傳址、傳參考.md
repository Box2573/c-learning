## 傳值( pass by value)
- 直接把值傳進去並`複製一份`做使用
- 就像用影印機一出一份副本，怎麼塗鴉修改都不會影響到正本
- 可以看到因為是複製一份進去做使用，所以原始的a數值不會被改變
```c++
void add (int x)
{
    x += 100;
}

int main()
{
	int a = 0;
    add (a);
    std::cout << a << "\n";

    return 0;
}

//output: 0
```

## 傳址(pass by address)
- 傳入一個指標也就是位址因此是傳址
- 就像把地址給裝修師傅，要拿著鑰匙 * ，才可以打開修改裡面東西
- 需要用 * 解址
- 可以看到因為是傳入a的位址，因此可以看成她修改了a
```c++
void add (int *x)
{
    *x += 100;
}

int main()
{
	int a = 0;
    add (&a);
    std::cout << a << "\n";

    return 0;
}

//output: 100
```

## 傳參考 (pass by reference)
- 傳變數的別名(alias)做使用
- 修改了別名就等於修改了本尊
- 就像同個人只是我用綽號叫他
```c++
void add (int &x)
{
    x += 100;
}

int main()
{
	int a = 0;
    add (a);
    std::cout << a << "\n";
    
    return 0;
}

//output: 100
```

### 為什麼 `int& x` 不是取址
- &放在變數那邊就是取址
- &放在型態那邊就是宣告參考
- 可以用&放在等號哪邊來思考
```c++
int number = 10;

int* ptr = &number;  // &number：取出 number 的位址
int& ref = number;   // int&：宣告參考，讓 ref 成為 number 的別名
```

### 那為什麼要用傳參址不用傳參考就好
- 傳參考看起來的確比傳址方便但
	- 傳參考不能為NUll
		- 傳參考是綽號表示他一定要有這個人我才有辦法幫他取綽號(不可能幫一個不存在的人取綽號)，甚至用綽號叫他，所以`傳參考用法不能為null`
		- 傳址如果覺得沒東西可以傳空的位址`(nullptr)`進去，就像這個地址現在不存在未來可能蓋房子就有地址了
	- 不能更改綁定
		- 因為一個綽號對應一個人，因此`傳參考可以看成是唯一的沒辦法更改`
		- 傳只可以改，就像地址填錯了修改這樣
