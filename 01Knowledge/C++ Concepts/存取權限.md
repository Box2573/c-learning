- private:子類別、外部都不允許使用
	- 外部不能使用hungry
	- 即使有人繼承Pet他也不能用
```c++
class Pet {
private:
    int hungry = 50;
};
```
- protected:子類別可以，外部不允許
	- 繼承Pet就可以用hungry
	- 但我覺得這樣會導致子類別過度使用或是任意修改可能會有耦合那些的
```cpp
class Pet {
protected:
    int hungry = 50;
};
```
- public 全部都可以用
```cpp
class Pet {
public:
    int hungry = 50;
};
```
