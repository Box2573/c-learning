## 繼承 
- 一樣打:表示繼承
- 前面可以加入[[存取權限]]
	- 預設計成你不打東西是private
```cpp
//private基底類別的public、protected都會變private
class Cat : private Pet {
}; 

//等於
class Cat :  Pet {
}; 
```
- protected會把基底類別public也變protected
```cpp
class Cat : protected Pet {
};
```
- public會保持public是public，protected維持protected
```cpp
class Cat : public Pet {
};
```
- 是一種表達is a關係例如Cat繼承Pet表示Cat is a Pet
- 是可以轉成基底類使用(隱式向上轉型)，但不代表private和protected不行
- 在 C++ 中`必須透過指標或引用才能生效`，這個就是多型
```cpp
Cat myCat("Mimi");
Pet* pet = &myCat;
```

### has a
- 表示...有...
- 下面例子可以看到PetShop有(has a)cat跟dog，但pet shop並不是一種pet
- 為Composition(組合)
```c++
class PetShop
{
	public:
		PetShop()
		{
			Cat myCat;
			Dog myDog;
		}
}
```

## 類別外定義
- 一般都是直接再class內宣告函式
- 類別外定義適合多檔案專案例如宣告放在.h檔在.cpp實作
```cpp
class Cat {
public:
    void forTest();//類別內宣告
};
```
- :: 可以理解為定位的GPS(……裡面的……)例如下面這個例子可以解讀成Cat裡面的forTest() 
```cpp
void Cat::forTest() 
{
    std::cout << "這是測試\n"; //類別外定義
	
}

int main ()
{
	Cat myCat();
	myCat.forTest();
}
```

## 多型
- 就是is a ，cat is a pet，dog is a pet都是多型
- 在 C++ 中`必須透過指標或引用才能生效`
### Virtual Function
- 可以看成是多型的實現手段
- 簡單來說就是方法名字一樣但行為不同例如遙控制都是電源鍵但開關行為對電視跟鐵捲門可能不同
- 通常用virtual 和 override
	- virtual允許被覆寫
	- override表示複寫
```cpp
class Pet {
public:
    virtual void eat();//可以不做讓子類別去實作
    virtual void eat()//或是可以實做一個預設的子類別可以不需要實作
	{
		 decreaseHungry(10);
	}
};

class Cat : public Pet {
public:
    void eat() override {
        decreaseHungry(20);
    }
};
```

### 普通虛擬函數與純虛擬函數
- 普通虛擬函數就是子類別不一定要實作
```c++
virtual void eat()//或是可以實做一個預設的子類別可以不需要實作
{
	 decreaseHungry(10);
}
```
- = 0為純虛擬函數，表示子類別一定要實作
- 如果一個class有純虛擬函數他就會變`抽象類別`
- 抽象類別`不能直接建立物件`
- 但抽象類別可以透過指標或參考來操作衍生類別物件
```cpp
class Pet {
public:
    virtual void eat() = 0;純虛擬函數
};

class Cat : public Pet {
public:
    void eat() override {
        decreaseHungry(20);
    }
};

class Dog :public Pet
{

    public:

        Dog(string dogName):

            Pet(dogName)

            {}

  

        void eat() override

        {

            decreaseHungry(10);

        }

};

int main ()
{

    Cat myCat("Mimi");

    Dog myDog("Bobo");

    Pet *petShop[] = {&myCat, &myDog};//抽象類別可以透過指標或參考來操作衍生類別物件

  

    for(Pet *pet : petShop)//可以這樣用同時操控所有都是Pet的物件

    {

        pet -> eat();

        cout << pet -> getName() << " 飢餓值: " << pet -> getHungry() << endl;

    }

  
  

    return 0;

}
```
