- 容器大致可以分為`序列`和`關聯`兩種

## 序列
- 資料依照位置或順序存放，有
	- array
		- 固定大小
	- vector
		- 動態大小
	- 不確定大小時首選vector

## 關聯
- 透過 Key 尋找資料
	- map
		- 一個鍵對一個值
		- 自動排序
	- set
		- 只有 Key，沒有 Value，或是說key本身就是value
		- 只在乎某筆資料是否有出現過，或避免資料重複時可以使用
		- 自動排序
	- unordered_map、unordered_set[[unordered_set]]
		- 使用[[雜湊表Hash table]]去實作
		- 資料沒有順序可言
		- 查詢某個資料時只要把key透過雜湊函數換算就知道存在哪，因此找尋速度快，除非遇到碰撞
	> 當今天資料非常大，我又不在乎順序，只想快速找到某些資料那很適合用unordered系列

| 需求            | 優先考慮            | 原因          |
| ------------- | --------------- | ----------- |
| 固定數量的資料       | `array`         | 不需要動態調整     |
| 數量會改變、需要連續儲存  | `vector`        | 動態調整大小      |
| 需要依 Key 排序    | `map`           | 自動維持 Key 順序 |
| 需要快速透過 Key 查詢 | `unordered_map` | Hash Table  |
| 只需要保存不重複的資料   | `set`           | 自動排序及去除重複   |
| 快速判斷資料是否存在    | `unordered_set` | Hash Table  |
