- 解構子會在物件生命週期結束時執行可能是一個函式結束使用之類的
- 寫法跟建構子差不多
- 可以用`default` 表示預設的解構子實作
>通常可以不用自己定義解構子，編譯器會自己處理，除非你有特殊需求要在物件銷毀時做，也就是
>物件的生命週期與資源管理綁定，物件結束生命時，自動釋放它所管理的資源(RAII)
```c++

~Pet()
{}
//或
~Pet() = default;
```
- 可以看到他執行的生命週期
	- 解構子會在main return 0後執行
```c++
class Test
{
	public:
	
	    Test()//建構子
	    {
	        cout << "生成\n";
	    }
	  
	
	    ~Test()//解構子
	    {
	        cout << "消失\n";
	    }
};

int main ()
{
	Test test;//這裡的建構子沒有傳入參數如果寫test()會變成一般函數宣告不會執行建(解)構子
    cout << "執行\n";
    
    return 0;
}
```

### 虛擬解構子
- 基底類別會透過指標刪除衍生類別物件時，需要虛擬解構子
	- 簡單來說就是我會不會透過刪除基底類別去刪除她的衍伸物件，例如我會透過刪除pet近而刪除cat那就要用虛擬解構子
	- 不是只要有繼承就一定需要
	- 通常用於多型
- 可以想成先刪除Cat在刪除Pet的感覺，刪的比較乾淨
> Cat如果不寫解構子，編譯器會自己產生一個，
> 父類別的虛擬解構子可以讓多型刪除正常運作，不代表每個子類別都必須自己寫解構子
```cpp
clsss Pet
{
	virtual ~Pet() = default;
};

clsss Cat : public Pet
{
};

int main()
{
	Pet* pet = new Cat("Mimi");
	delete pet;
	
	return 0;
}
```
