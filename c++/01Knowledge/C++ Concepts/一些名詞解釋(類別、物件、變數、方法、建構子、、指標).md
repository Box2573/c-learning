
## 類別
類別就像藍圖例如車子設計圖
`C++的class}後面要加;`
```c++
class Car
{};
```

## 物件
物件就像生產出來的東西例如跑車
- `Car`是類別
- `myCar`是物件
```c++
Car myCar("sportCar");
```

## 變數(屬性)
儲存資料的變數例如車子是藍色的
```c++
class Car
{
	string color = "blue";
};
```

## 方法(函式)
可以執行的行為例如車子可以前進
```c++
class Car
{
	string color = "blue";
	
	void moveForward()
	{
	}
};
```

## 建構子
創造一個新物件（物件剛出生）的時候，系統會**自動觸發、第一個執行的功能**，專門用來設定初始值
例如車子剛出廠時可以選擇顏色
- 建構子也可以類別外定義通常用在[[標頭檔和多個檔案用指令編譯以及運作方式]]和實作定義分開時
```c++
class Car
{
	string color;
	
	Car(String color)
	{
		this -> color = color;
	}
};
```
- 在建構子裡面賦值這樣是先宣告變數在賦值對於一些例如const的東西會報錯
- 可以用`初始化列表`方式
  - ()裡面的是建構子傳進來的變數
  - ()前面是該class的變數
  - 如有多個變數要初始化直接,繼續寫即可
```c++
class Car
{
	string color;
	
	Car(String mycolor):
		color(mycolor),
		繼續寫在這
	{
		
	}
};
```
- 如果要往上傳給基底類別的建構子(也就是繼承的class)寫法一樣只是變數換成該繼承的class名稱就類似把值傳入基底類別建構子
```c++
class Car
{
	string color;
	
	Car(String mycolor):
		color(mycolor)
	{
	}
};

class SportCar : public Car
{
	string color;
	
	Car(String color):
		Car(color)
	{
	}
};

```


## 指標(pointer)
儲存物件在**記憶體中實際位址**的變數例如車子在展示車的位子
- 兩種寫法都可以
- 取得位址用& &sportCar = 把sportCar位址傳給`*car`，因此現在*car紀錄的是他的位址
- 要使用的的話一樣要打一個`*`才可以取得她的資料(取值運算)
```c++
Car *car;
Car* car;

Car sportCar;
Car *car = &sportCar;//可以想成一個指向型態為Car的空間

(*car).color = "red";//.的優先度比*高如果不打()會變成去取得car的color但car是存地址因此沒有color會報錯
car -> color = "red";//可以簡寫成這樣
```
>使用delete時刪掉的是指標指向的物件，例如在這邊delete car的話是刪掉&sportCar，但car變數本身還會存在但會變成懸空指標，如果不想讓他懸空，可以再delete完後讓他指向null，car變數則是會在出了作用域後自動回收
