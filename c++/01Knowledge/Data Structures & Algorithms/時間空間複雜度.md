# 時間複雜度
## 快到慢排序
- O(1)      固定

- O(log n)  每次砍一半

- O(n)      全部走一次

- O(n log n) 全部走一次，每次又有「砍一半」的操作

- O(n²)     每個都跟很多元素比較

- O(2ⁿ)     每個元素都有兩種選擇

- O(n!)     嘗試所有排列

## 介紹

### 時間是什麼

這裡的時間指的並不是執行花幾秒，而是`跑幾次`例如n=10，那就試跑10次

### n是什麼

n就是有幾項，例如`vector<int> nums = {1, 2, 3, 4, 5}`那n就是5

### Big O 只保留最高次項，忽略常數和低次項

>Big O 只保留最高次項

- 舉例來說Contains Duplicate這題的暴力破解優畫後的版本
```c++
for(int i=0;i<n;i++)
{
    for(int j=i+1;j<n;j++)
    {

    }
}
```
- 可以看到
    - j執行(n-1)/2
    - 因此總共執行n(n-1)/2，展開就是`(n² - n)/2`
    - 只保留最高次項因此是n²也就是O(n²)
    - 詳細的n(n-1)/2怎麼得到看Contains Duplicate的note
>巢狀迴圈要算的是「最裡面那段程式總共被執行幾次」，例如這裡if移時已經被算在j裡面了

### O(1)固定

- 執行次數固定
- 例如取陣列中的某個元素`int x = nums[3];`

### O(n)全部走一次

- 執行n次=全部跑一次
- 例如遍歷整個陣列`for (int i = 0; i < n; i++)`

### O(n²) 每個都跟很多元素比較

```c++
for (int i = 0; i < n; i++)
{
    for (int j = 0; j < n; j++)
    {
    }
}
```
- 可以看到上述例子
    - i要執行n次
    - j也執行n次
    - 因此執行n*n次也就是n²次

### 空間複雜度
- 空間也是用O表示
- 她只看輸入資料變大時，需要的額外空間會不會跟著增加

`不是看有幾個變數`

- O(1) 每個變數都只佔用固定大小的記憶體
    - ex
    ```c++
    int n = nums.size();
    int i = 0;
    int j = 0;
    int result = 0;
    ```
    看起來有4個變數對吧，但實際上他們不會佔據超過1個記憶體空間i、j、result很好理解畢竟他們都只是個整數，而n也是個只紀錄size的整數nums有100個東西他也只會紀錄100
- O(n) 空間會隨著輸入大小一起成長
    - ex
    ```c++
    vector<int> copy = nums;
    ```
    nums如果有100個數值他都會全部複製到copy因此是
    O(100)->O(n)不會寫成O(100)
