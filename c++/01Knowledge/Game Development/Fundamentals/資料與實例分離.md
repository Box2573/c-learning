- 這個用法很好方便擴充也不用每個都改動
- 例如三種武器：劍 (Sword)、弓 (Bow)、法杖 (Staff)每個武器都有`攻擊力`、`重量`、`耐久度`屬性，
	- 那照以前寫法可能會先寫出一個weapon calss再讓所有武器去繼承，但如果今天我要新增一個攻擊範圍屬性好了，是不是每個class都還要去做新增的動作
	- 因此採用資料分離可以集中管理也可以達到不用每次都要改所有class
-  下面用武器當例子
	- 我們用enum宣告物品種類[[enum class vs enum]]，struct或class宣告物品可能有的屬性或行為[[struct vs class]]
```c++
enum class Weapontype
{
    sword,
    bow
};

struct WeaponData
{
    int damage = 1;
    int weight = 2;
};
```
- 用一個map去儲存鍵值對應各種武器當database可以方便儲存查找武器(也可以用其他資料型態去儲存)
	- 如果WeaponData其中一項不打數值他就是預設的
		- 例如bow的weight不打那他就是預設的2
```c++
int main()
{
    std::unordered_map<WeaponType, WeaponData> weapondataBase =
    {
        {WeaponType::sword, {5, 3}},
        {WeaponType::bow, {5}}
    };
    
    WeaponType sword = WeaponType::sword;
    WeaponType bow = WeaponType::bow;
    
    const WeaponData &currentWeapon = weapondataBase.at(sword);
    const WeaponData &nextWeapon = weapondataBase.at(bow);

    std::cout << "劍傷害值: " << currentWeapon.damage << " , 重量 " << currentWeapon.weight << "\n";
    std::cout << "弓傷害值: " << nextWeapon.damage << " , 重量 " << nextWeapon.weight << "\n";
//bow的weight不打那他就是預設的2
    return 0;
}
```
