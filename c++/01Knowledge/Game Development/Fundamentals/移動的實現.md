- 和跳躍差不多
- 現在距離 = 現在距離 + 移動距離
	-   移動距離 = 方向 * 速度 * 時間
>[!warning] 一樣注意最後計算移動距離時不能用=不然會導致角色瞬移，例如我剛好不按移動鍵方向會等於0導致移動距離跟著等於0，那假設我今天角色明明再x=6的地方那會瞬間變成0

- 用horizon表示往左或往右移動
- 採用兩個if而不是if-else[[if else與獨立if的選擇]]這樣可以達成同時按下+1-1剛好=0因此同時按下AD角色不會動
- `float horizontal = 0.f`會使horizon一直清0因此不用擔心我一值按A或D數值一直累加進而影響到移動距離
```c++
 #pragma region Move
        float horizontal = 0.f;//移動方向
        if(sf::Keyboard::isKeyPressed(sf::Keyboard::Key::A))//按下往左
            horizontal -= 1.f;
        if(sf::Keyboard::isKeyPressed(sf::Keyboard::Key::D))//按下往右
             horizontal += 1.f;

        //現在距離 = 現在距離 + 移動距離，  移動距離 = 方向 * 速度 * 時間
        Player::x += horizontal * Player::moveSpeed * deltaTime;

        #pragma endregion
```
