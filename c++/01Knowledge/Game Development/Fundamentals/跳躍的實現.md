- 跳躍不能直接改玩家的y值會導致看起來像瞬移沒有那種慢慢上去的感覺
- 因此這裡採用半隱式歐拉[[歐拉積分，讓電腦模擬現實的運動]]來實現跳躍
	- 先計算速度再去更新位置
- 可以根據等加速度公式 $v = v_0 + at$去計算
	- V為最終速度
	- $V_0$ 為初始速度
	- a為加速度(Acceleration)
	- t為時間
- 因此可以思考出我們大概需要
	- velocitY用來紀錄最終速度
	- jumpVelocity為初始速度，這個會決定跳多高
	- gravity可以當成加速度
- 跳躍按下時，如果在地上
	- 觸發跳躍機制
		- 最終速度=初始速度
		- 離開地面後一直加上重力
		- 並更新位置
>[!warning] 注意更新位置y不是單純用=而是y要累加，半然用=會導致角色被傳送，例如假設剛好算玩重力那些=0直接把y=0會導致角色瞬移到地上

>[!warning] 重力通常是負的，但在sfml採用螢幕座標系因此往下是+y，因此跳躍也是反過來是-y
- $at$ 就是delta time表示這個角色在這個frame實際移動的距離這樣不會導致
	- 如果有人的電腦室144fps會導致一秒算了144次導致位移更大之類的
	- 實現方法可以看[[delta time的實現與使用時機]]


- 目前還是採用地板是個水平線
	- 玩家的左上角就是我們指定的位置因此要檢測下方是否為地板要找到玩家腳底用玩家y+玩家高度，當這個數值>=地板就可以看成她到達地板，但他還是會繼續往下掉因此要歸0速度和位置要回到地面之上
```c++
//跳躍相關參數
const float jumpVelocity = -700.f;//sfml y朝上是負的
const float gravity = 2000.f;

void Player::update(float deltaTime)
    {
        //jump
        //判斷是否在地上
        if(isGround())
        {
            //避免穿過地板和歸0速度
            Player::y =  Player::groundY -  Player::height;
            Player::velocityY = 0;

            //先檢查是否按下跳躍鍵
            //觸發跳躍
            if(sf::Keyboard::isKeyPressed(sf::Keyboard::Key::Space))
            {
                std::cout << "Jump!\n";
                jump();
            }
        }
        else//不在地上，表示在空中一直扣掉重力
        {
            //這一幀因為重力而新增的速度 = 加速度 * delta time
            //不乘delta time會導致可能fps很高會導致重力被加很多次
            Player::velocityY += Player::gravity *deltaTime;//sfml往下是+y因此+重力
        }
        //更新位置，這一幀實際上走過的距離 = 速度*delta time
        Player::y += Player::velocityY * deltaTime;
    }

    void Player::jump()
    {
        //jump
         Player::velocityY = Player::jumpVelocity;
        
    }
    
    bool Player::isGround() const
    {
        return Player::y + Player::height >= Player::groundY;
    }
```
